IAC - Orchestration
===================

There are many IAC tools in wild. Two that are commonly used in Network Automation are __Terraform__ and __Ansible__. 

Terraform
---------

Is a declarative solution where you state the intent via *.tf* file with the required providers and it terraform will get you to the desired state. 

Ansible
-------
Ansible is a procedural based and requires you to write the desired state in a yaml file.
